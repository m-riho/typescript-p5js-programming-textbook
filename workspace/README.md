# 自分のプログラムを保存する場所

`workspace/` は、学生のみなさんが自分で作成したTypeScriptプログラムを保存するフォルダです。教材リポジトリの直下にあり、`listings/` や `typescript-p5/` と同じ階層にあります。

- 授業中の練習、試行錯誤、自由制作の `.ts` ファイルは、基本的にこのフォルダ以下へ保存します。たとえば `workspace/first-sketch.ts` のように、内容が分かる名前を付けます。
- 演習問題・課題のプログラムは、[exercises/](exercises/) に保存します。ファイル名は `02-01.ts` のように、章番号と問題番号をそれぞれ2桁で書きます。
- 教材本体の `typescript-p5/src/` や設定ファイルは、教材や担当教員の指示がある場合にだけ変更してください。`listings/` のサンプルを変更して作品を作る場合も、自分のプログラムは `workspace/` 以下へ保存します。

## 保存したプログラムを試すとき

現在の教材では、`typescript-p5/src/main.ts` の内容をブラウザで実行します。`workspace/` に保存しただけでは実行されず、このフォルダ内のファイルは現在の `npm run build` の型チェック対象にも含まれません。

教材の手順で `main.ts` を編集したときは、別のサンプルで上書きする前に、残したい内容をこのフォルダ以下へコピーして保存してください。VS Codeで保存先の新しい `.ts` ファイルを作り、`main.ts` の内容全体を貼り付けて保存できます。

保存したプログラムを試す場合は、その内容全体を `typescript-p5/src/main.ts` へコピーして保存し、教材と同じ手順で実行します。実行後に `main.ts` を修正した場合は、保存先のファイルにも修正を反映してください。2つのファイルは自動では同期されません。画像・JSON・音声などの素材は、各章で指定された場所に置きます。

作業の節目には、`main.ts` だけでなく、`workspace/` 以下に保存したファイルもGitのコミット対象にします。提出方法は担当教員や学内LMSの指示に従ってください。
