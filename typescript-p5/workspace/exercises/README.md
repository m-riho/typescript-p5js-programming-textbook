# 演習問題・課題のプログラム

各章の演習問題や課題で作成したTypeScriptファイルは、`typescript-p5/` 内にある、この `workspace/exercises/` フォルダに保存します。

ファイル名は `章番号-問題番号.ts` とし、章番号と問題番号をそれぞれ2桁で書きます。1桁の番号には先頭に `0` を付けます。

| 課題 | ファイル名 |
|---|---|
| 第2章 問題1 | `02-01.ts` |
| 第2章 問題2 | `02-02.ts` |
| 第3章 問題5 | `03-05.ts` |
| 第10章 問題3 | `10-03.ts` |

たとえば第2章の問題1の保存先は、教材リポジトリの直下から見て `typescript-p5/workspace/exercises/02-01.ts` です。名前をそろえると、ファイル名で並べたときに章・問題の順番になり、どの課題のプログラムか分かりやすくなります。

プログラムを作成する課題にこのルールを使います。文章で答える問題や、複数のファイルを使う課題は、担当教員の指示に従ってください。

`typescript-p5/index.html` の既存のmodule scriptの `src` を `/workspace/exercises/02-01.ts` のように変更すると、選んだファイルが直接実行されます。詳しい手順と型チェックの方法は、[workspaceの説明](../README.md)を確認してください。保存したファイルと実行先の変更もGitで記録し、提出は担当教員や学内LMSの指示に従います。
